# Sales Data Analysis

## Project Overview
This project focuses on cleaning, validating, and analyzing sales data to identify business trends and performance patterns. An interactive Power BI dashboard was developed to support data-driven decision-making.

## Objectives
- Clean and validate the dataset.
- Investigate missing values, duplicates, data types, and date-related issues.
- Analyze sales, profit, product categories, regions, and monthly trends.
- Present key performance indicators through an interactive dashboard.
- Derive actionable business insights and recommendations.

## Tools & Technologies
- Python
- Pandas and NumPy
- Jupyter Notebook
- Microsoft Power BI

## Data Preparation & Validation
The analysis includes reviewing data types, checking missing values and duplicates, validating dates, and investigating unusual records.

Data quality issues are documented, and any corrections or exclusions are based on the findings of the analysis.

## Key Performance Indicators
- Total Sales
- Total Profit
- Quantity Sold
- Sales and Profit Trends
- Regional Performance
- Product Category Performance

## Dashboard
The Power BI dashboard presents key metrics, sales trends, category comparisons, and regional performance to help users explore the data interactively.
